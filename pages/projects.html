Sports Court Booking System

Backend Ready

前後端分離的運動場地預約系統，實作即時預約、取消與重複預約防護，著重後端架構與資料一致性。

FastAPI Python MySQL REST API Backend
  • 使用 FastAPI 建立 RESTful API，清楚分離前後端責任。
  • 資料庫設計加入唯一索引（場地 + 時段），防止重複預約。
  • 支援預約取消，並限制已過期時段不可操作。
  • 專案結構模組化，方便後續擴充前端、會員或權限系統。
